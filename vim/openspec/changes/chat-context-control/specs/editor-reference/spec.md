## ADDED Requirements

### Requirement: 引用编辑器代码切换按钮
输入框区域 SHALL 提供一个"引用编辑器代码"按钮，点击后切换引用状态。默认状态为未引用。

#### Scenario: 点击引用按钮开启引用
- **WHEN** 用户点击引用按钮（未引用状态）
- **THEN** 引用状态切换为已引用，输入框上方显示引用标签

#### Scenario: 点击引用按钮关闭引用
- **WHEN** 用户点击引用按钮（已引用状态）
- **THEN** 引用状态切换为未引用，输入框上方引用标签消失

#### Scenario: 默认状态
- **WHEN** 对话面板首次加载或重新打开
- **THEN** 引用状态为未引用，不显示引用标签

### Requirement: 引用标签展示
当编辑器代码被引用时，输入框上方 SHALL 显示一个 chip 标签，包含代码预览和取消按钮。

#### Scenario: 引用标签显示代码预览
- **WHEN** 用户开启引用且编辑器内有代码
- **THEN** 显示 chip 标签，内容为编辑器代码前 30 个字符的截断预览

#### Scenario: 引用标签取消引用
- **WHEN** 用户点击 chip 标签的取消按钮（×）
- **THEN** 引用状态切换为未引用，标签消失

#### Scenario: 编辑器为空时引用
- **WHEN** 用户开启引用但编辑器内无代码
- **THEN** chip 标签显示"(空)"预览

### Requirement: 基于引用状态构建 API 消息
发送消息时 SHALL 根据引用状态决定是否附加编辑器代码上下文。多轮对话历史 SHALL 始终包含在 API 消息中。

#### Scenario: 已引用时发送消息
- **WHEN** 引用状态为已引用且用户发送消息
- **THEN** API 消息包含完整多轮对话历史，并在末尾附加当前编辑器代码作为上下文消息

#### Scenario: 未引用时发送消息
- **WHEN** 引用状态为未引用且用户发送消息
- **THEN** API 消息仅包含多轮对话历史，不附加编辑器代码

#### Scenario: 多轮对话始终加载
- **WHEN** 用户发送消息（无论引用状态）
- **THEN** API 消息始终包含之前的对话历史
