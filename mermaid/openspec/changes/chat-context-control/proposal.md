## Why

当前 AI 助手每次发送消息都会自动附加编辑器代码作为上下文，用户无法控制是否引用编辑器内容。这导致不必要的 token 消耗，且用户无法明确表达"这次对话不需要参考编辑器代码"的意图。需要让用户手动选择是否引用编辑器代码，同时保持多轮对话历史默认加载的行为。

## What Changes

- 输入框区域新增"引用编辑器代码"按钮，用户点击后切换引用状态
- 引用时在输入框上方显示引用标签（chip 样式），展示代码片段预览，点击可取消引用
- 默认不引用编辑器代码，改为用户主动选择
- 多轮对话历史默认加载（保持现有行为）

## Capabilities

### New Capabilities
- `editor-reference`: 在输入框区域提供引用编辑器代码的交互控件，包括切换按钮、引用标签展示和状态管理

### Modified Capabilities
（无已有 spec 需要修改）

## Impact

- `ChatPanel.vue`: 输入框区域 UI 改造，新增引用状态管理和样式
- `src/utils/chat.js`: 无需修改，消息构建逻辑在 ChatPanel 内完成
